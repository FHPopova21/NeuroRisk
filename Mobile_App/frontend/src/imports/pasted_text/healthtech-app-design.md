Design a modern iOS-style mobile app UI for a healthtech application focused on EEG monitoring and seizure risk assessment.

IMPORTANT:
The mobile app must visually match an existing doctor web dashboard. Reuse the same design system:
- soft green primary color (calm, medical tone)
- secondary colors: orange (warning), red (high risk), blue (info)
- rounded cards, soft shadows, clean typography
- minimal, premium, Apple-like interface

STYLE:
- iOS native feel (like Apple Health / Calm / Headspace)
- soft gradients (green → mint → light blue)
- glassmorphism elements (subtle blur)
- smooth spacing, large touch areas
- elegant and calming, but still clinical and precise

----------------------------------

SCREENS TO DESIGN:

1. ONBOARDING / INTRO ANIMATION SCREEN
- Fullscreen minimal layout
- Center: animated brain illustration
- EEG wave smoothly animating across the brain
- Text:
  "Understand your brain activity"
  "Real-time monitoring. Smarter insights."
- Button: "Get Started"
- Very clean, almost no clutter

----------------------------------

2. HOME DASHBOARD (PATIENT)
- Greeting: "Hello, [Name]"
- Main Card (BIG):
  - Current Risk Level (LOW / MEDIUM / HIGH)
  - Animated pulse or glow effect
  - Subtitle: "Based on latest EEG analysis"

- Secondary cards:
  - Last recording (time)
  - Weekly summary (mini chart)
  - Status: "Monitoring Active"

- Floating button:
  "Start Monitoring"

----------------------------------

3. LIVE MONITORING SCREEN
- Real-time EEG waveform (animated line chart)
- Status indicator:
  - Green = stable
  - Orange = warning
  - Red = high activity

- Info:
  - Duration
  - Signal quality
- Subtle motion everywhere

----------------------------------

4. HISTORY / ANALYSIS SCREEN
- List of past analyses (cards)
Each card:
  - Date & time
  - Risk level badge
  - Small chart preview

- Tap → opens detail view

----------------------------------

5. ANALYSIS DETAIL SCREEN
- Large risk indicator (circle / gauge)
- EEG waveform visualization
- Section: "What influenced this result"
  - feature contributions (bars or tags)

- Doctor notes section:
  - "Doctor feedback"
  - clean readable card

----------------------------------

6. PROFILE SCREEN
- Patient ID
- Email
- Status (Active / Connected to doctor)
- Settings
- Logout button

----------------------------------

UX DETAILS:
- Smooth transitions between screens
- Subtle microinteractions (hover, tap, loading)
- Use skeleton loaders for data
- Prioritize clarity over complexity

----------------------------------

MOOD:
Calm, safe, medical, trustworthy, slightly futuristic

DO NOT:
- make it too dark or aggressive
- avoid clutter
- avoid too many colors
